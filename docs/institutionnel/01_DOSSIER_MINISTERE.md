## 1. RÉSUMÉ EXÉCUTIF

DeNoTa est une plateforme numérique ivoirienne qui **révèle les talents sportifs** de Côte d'Ivoire et les **connecte aux décideurs** (clubs, agents, fédérations).

**Notre ambition** : Devenir la **vitrine officielle du sport ivoirien** et un outil stratégique pour le Ministère des Sports.

**Notre positionnement** : DeNoTa est **complémentaire au SIGS et au JTS**. Nous ne remplaçons rien. Nous apportons la vitrine digitale qui manque à l'écosystème.

**Notre demande** : Un **partenariat technique** pour :
1. Accéder aux données sportives nationales
2. Faciliter l'adoption par les fédérations
3. Obtenir une reconnaissance officielle
4. Intégrer le programme JTS

---

## 2. LE PROBLÈME

### Constat
- **Des milliers de jeunes talents** en Côte d'Ivoire restent invisibles.
- **Les clubs et agents** manquent d'outils pour détecter hors de leurs réseaux.
- **Les fédérations** n'ont pas de cartographie nationale des talents.
- **Le Ministère** n'a pas de données en temps réel sur le potentiel sportif national.

### Le JTS a identifié ces problèmes
Le Programme National de Détection des Jeunes Talents Sportifs (JTS) reconnaît :
- "Cadre non structuré"
- "Inégalités géographiques"
- "Faible intégration technologique"
- "Manque de synergie"

**DeNoTa résout ces 4 problèmes.**

---

## 3. LA SOLUTION DeNoTa

### 3.1. Pour les talents
- Profil sportif vérifié
- Upload de vidéos
- Talent Score™ (score composite sur 100)
- Visibilité auprès des recruteurs

### 3.2. Pour les clubs et agents
- Recherche avancée (sport, ville, âge, niveau)
- Carte interactive des talents
- Rapports de scouting PDF
- Messagerie directe

### 3.3. Pour les fédérations
- Vue globale par discipline
- Statistiques nationales
- Export de données
- Suivi des licences

### 3.4. Pour le Ministère
- **Cartographie nationale** des talents
- **Données analytics** pour la décision
- **Détection précoce** pour les JO, CAN
- **Vitrine internationale** du sport ivoirien
- **Complémentarité avec le JTS** : DeNoTa cible les 15-25 ans

---

## 4. COMPLÉMENTARITÉ AVEC LE SIGS ET LE JTS

### 4.1. Le SIGS (Système d'Information et de Gestion du Sport)
- **Rôle** : Back-office administratif
- **Fonctions** : Gestion des clubs, fédérations, licences
- **Ce que DeNoTa apporte** : Une API pour synchroniser les profils talents

### 4.2. Le JTS (Programme National de Détection des Jeunes Talents Sportifs)
- **Rôle** : Détection des talents
- **Public** : 10-18 ans
- **Ce que DeNoTa apporte** : Le prolongement pour les 15-25 ans, la vitrine digitale, l'analyse vidéo, la mise en relation

### 4.3. Tableau comparatif

| Critère | JTS | DeNoTa |
|---------|-----|--------|
| Public | 10-18 ans | 15-25 ans |
| Approche | Détection de masse | Détection continue |
| Sports | 70+ | 4 pilotes |
| Fonctions | Inscription, tri | Vidéo, Talent Score™, scout reports |
| Business | Public (gratuit) | Freemium + commissions |
| Couverture | Nationale | Abidjan puis national |
| Technologie | Microservices | Flutter, Supabase |
| Vitesse | Lente | Rapide |

### 4.4. Message clé

> "Le SIGS gère. Le JTS détecte. **DeNoTa révèle.**"
