## 1. POUR FONTSI
### Fonds pour la Science, la Technologie et l'Innovation

### Notre projet
DeNoTa est une plateforme numérique ivoirienne qui digitalise la détection des talents sportifs.

### Notre innovation
- **Talent Score™** : Algorithme de notation composite (IA + experts)
- **Analyse vidéo** : Extraction automatique de métriques sportives
- **Carte interactive** : Visualisation géographique des talents
- **API** : Intégration avec les systèmes existants (SIGS, JTS)

### Notre impact
- **Économique** : Création d'emplois tech, valorisation du sport ivoirien
- **Social** : Égalité des chances pour les jeunes défavorisés
- **Sportif** : Détection des futurs champions
- **Technologique** : Innovation ivoirienne exportable

### Notre demande
- **Subvention** : 5-20 M FCFA
- **Accompagnement** : Mentorat, réseau
- **Visibilité** : Label FONTSI

### Notre alignement
- Complémentarité avec SIGS et JTS
- Alignement avec la politique sportive nationale
- Conformité au cadre légal ivoirien

## 2. POUR ANSUT
### Agence Nationale du Service Universel des Télécommunications/TIC

### Notre projet
DeNoTa a besoin d'infrastructure pour héberger :
- Vidéos (stockage)
- Base de données (Supabase)
- API (microservices)
- CDN (diffusion)

### Notre impact
- **Couverture** : 31 régions à terme
- **Inclusion** : Accès pour les zones rurales
- **Digitalisation** : Contribution à la transformation numérique
- **Souveraineté** : Données hébergées en Côte d'Ivoire

### Notre demande
- **Hébergement** : Serveurs, bande passante
- **Connectivité** : Accès pour les zones rurales
- **Accompagnement** : Support technique

### Notre alignement
- Complémentarité avec SIGS et JTS
- Alignement avec la stratégie numérique nationale
- Conformité au cadre légal ivoirien
