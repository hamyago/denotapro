# NOTE STRATÉGIQUE
## DeNoTa face au SIGS et au JTS

**Date** : Juillet 2026
**Auteur** : Fondateur DeNoTa
**Destinataire** : Équipe DeNoTa

---

## 1. SYNTHÈSE

Le Ministère des Sports a lancé 2 plateformes :
- **SIGS** : Back-office administratif
- **JTS** : Détection des jeunes talents

**DeNoTa est complémentaire, pas concurrent.**

---

## 2. ANALYSE DU SIGS

### Ce que fait le SIGS
- Gestion des clubs et fédérations
- Gestion des licences
- Tableaux de bord ministériels
- Interconnexion avec les systèmes gouvernementaux

### Ce que le SIGS ne fait PAS
- Détection de talents
- Analyse vidéo
- Mise en relation talent ↔ club
- Expérience mobile

### Chiffres clés
- 77+ fédérations
- 580+ clubs
- 70+ disciplines

### Opportunités
- **FONTSI** : Financement innovation
- **ANSUT** : Infrastructure, hébergement
- **API** : Intégration possible

---

## 3. ANALYSE DU JTS

### Ce que fait le JTS
- Inscription des jeunes talents
- Tri des profils
- Regroupements régionaux
- API d'intégration

### Ce que le JTS ne fait PAS
- Analyse vidéo automatisée
- Talent Score™
- Mise en relation directe
- Monétisation
- Expérience mobile native

### Public cible
- 10-18 ans
- 31 régions
- 70+ disciplines

---

## 4. POSITIONNEMENT DeNoTa

### Complémentarité

| JTS | DeNoTa |
|-----|--------|
| Détection de masse | Détection continue |
| Regroupements ponctuels | Vitrine permanente |
| 10-18 ans | 15-25 ans |
| 70+ disciplines | 4 pilotes |
| Public (gratuit) | Freemium + commissions |
| Microservices | Flutter, Supabase |

### Message clé

> "DeNoTa est le front-office digital du JTS.
> Le SIGS gère. Le JTS détecte. DeNoTa révèle."

---

## 5. RECOMMANDATIONS

### 5.1. Alignement
- Reprendre les 4 disciplines du JTS
- Utiliser le même vocabulaire
- Cibler les 31 régions à terme

### 5.2. Partenariat
- Proposer un protocole d'accord
- Demander accès API au SIGS
- S'intégrer au JTS

### 5.3. Financement
- Solliciter FONTSI via le Ministère
- Demander hébergement ANSUT

### 5.4. Communication
- Communication conjointe au lancement
- Mention "Partenaire du Ministère des Sports"
